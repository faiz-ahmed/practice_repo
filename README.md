# To-Do List

A minimal to-do list web app. Plain HTML, CSS and JavaScript, with no build step and no dependencies.

## Use it

Open `index.html` in your browser (double-click it).

- Type a task and press **Enter** or click **Add**
- Tick the checkbox to mark a task done (tick again to undo)
- Click **Delete** to remove a task

Tasks are saved in your browser's local storage, so they're still there after you reload or reopen the page. They live only in that browser on that device.

## Files

- `index.html`: page structure
- `style.css`: styling (follows your system's light/dark mode)
- `app.js`: add, complete, delete and save logic
